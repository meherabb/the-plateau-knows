# `paper/`

LaTeX source for the submission, self-contained and ready to build.

```bash
cd paper
pdflatex main.tex && bibtex main && pdflatex main.tex && pdflatex main.tex
```

- `main.tex` — full paper source (9-page body, unlimited references/appendix).
- `references.bib` — 25 bibliography entries, each verified against a real
  source and individually cited (no entry is present without a corresponding
  `\citep`/`\citet` in the text).
- `iclr2027_conference.sty` — a faithful reconstruction of the standard ICLR
  LaTeX conference style. **This is not the official venue file.** Swap it
  for the current official style file from the submission portal before
  final submission; the structure and macros here match the standard format
  closely enough to compile and preview correctly in the meantime.
- `figures/` — all figures the paper's `\includegraphics` calls reference,
  copied directly from `results/figures/` (the complete set, including the
  two figures generated by the pipeline but not placed in the final paper,
  lives in `results/figures/`).
- `main.pdf` — a pre-compiled build for convenience. Regenerate it after any
  edit rather than trusting a stale copy.
